# Запросы к коллекции `orders` (база `shopdb`)

| № | Тип                        | Фильтр                                      | Найдено |
|---|----------------------------|---------------------------------------------|---------|
| 1 | Точное совпадение          | `{ "status": "paid" }`                      | 2       |
| 2 | Вложенное поле через точку | `{ "customer.email": "alex@example.com" }`  | 1       |
| 3 | Элемент массива            | `{ "tags": "electronics" }`                 | 3       |
| 4 | Оператор сравнения         | `{ "total": { "$gt": 2000 } }`              | 3       |
| 5 | `$exists`                  | `{ "customer.phone": { "$exists": true } }` | 4       |
| 6 | Сломанный запрос           | `{ "total": { $gt: 1000 } }`                | ошибка разбора |

## Пояснения

**1. Точное совпадение.** Ищем заказы со статусом `paid`. В коллекции их два — `ORD-1001` и `ORD-1004`.

**2. Вложенное поле через точку.** Обращаемся к полю внутри вложенного объекта `customer`. Совпадает один заказ — `ORD-1003` (Алексей Кузнецов).

**3. Элемент массива.** MongoDB ищет значение как элемент массива `tags`. Подходят три заказа с тегом `electronics`: `ORD-1001`, `ORD-1002`, `ORD-1003`.

**4. Оператор сравнения.** `$gt: 2000` — сумма строго больше 2000. Подходят `ORD-1001` (4500), `ORD-1003` (8900) и `ORD-1004` (2100).

**5. `$exists`.** Проверяем наличие поля `customer.phone`. Оно есть у четырёх документов; в `ORD-1005` поля нет.
